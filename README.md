# Prompt Template Generator

可交互 MVP：按场景（写作/客服/编程/营销）+ 目标 + 语气 + 约束，生成结构化 Prompt（含变量占位），支持复制。

## 功能
- 四种场景模板切换
- 结构化 Prompt 自动生成
- 一键复制，移动端可用
